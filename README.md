Course Catalog Management System

About the Project

A REST API project built with Java and Spring Boot to manage course information.

Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Gradle
- Git and GitHub

Features

- REST API endpoints for course operations
- Course entity and status management
- Repository layer using Spring Data JPA
- MySQL database configuration
- Application configuration using properties and YAML

Project Structure

- "controller" — Handles HTTP requests
- "entity" — Defines the Course entity and status
- "repository" — Provides database access
- "service" — Contains course-related business logic
- "exception" — Handles application exceptions
- "resources" — Stores application configuration

Configuration

Configure your MySQL connection and set the "DB_PASSWORD" environment variable before running the application. Never commit database passwords or other secrets.

Running the Project

1. Install the required JDK and MySQL.
2. Configure the database connection.
3. Open the project in IntelliJ IDEA.
4. Run "LearningappApplication".
